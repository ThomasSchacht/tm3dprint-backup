TM3DPRINT Backup

TM3DPRINT Backup is a private backup application used by TM3DPRINT I/S.

The application uses Rclone and Google Drive to store encrypted backups of our website, database, and related server files.

Backup data is encrypted using Restic before being transferred to Google Drive.

This application is intended for internal administrative use only and is not a public customer service.
